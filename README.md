# ARIMA & SARIMA for Trends Prediction

Proyek analisis dan prediksi data time series (tren) menggunakan model **ARIMA** dan **SARIMA**, dengan data yang diambil dari Google Trends (multiTimeline).

## Isi Repository
- `P1LC4_Set_1_fawwaz_rifat.ipynb` — notebook eksplorasi data time series, uji stasioneritas, pembangunan model ARIMA/SARIMA, dan evaluasi hasil prediksi.
- `multiTimeline.csv` — dataset tren yang digunakan (bersumber dari Google Trends).

## Metodologi
Notebook mencakup analisis pola musiman dan tren pada data time series, uji stasioneritas (misalnya ADF test), penentuan parameter model (p, d, q) dan (P, D, Q, s) untuk ARIMA/SARIMA, pelatihan model, serta evaluasi hasil forecasting.

## Cara Menjalankan
1. Clone repository ini.
2. Pastikan library `statsmodels`, `pandas`, dan `matplotlib` sudah terinstal.
3. Buka `P1LC4_Set_1_fawwaz_rifat.ipynb` di Jupyter Notebook.
4. Jalankan seluruh sel secara berurutan untuk mereproduksi hasil prediksi tren.
